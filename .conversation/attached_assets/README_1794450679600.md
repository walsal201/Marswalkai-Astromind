# AstroMind v2: AI Space Mission Suite

Rebuild of https://walsal201.github.io/ai-astromind/ with the **IBM watsonx Config (API key / Project ID) section removed**. The app works the moment it starts.

## What's inside
| File | Purpose |
|---|---|
| `index.html` | Complete front end (Home, AstroMind planner, MarswalkAI). Served by the backend. |
| `main.py` | FastAPI app, CORS, rate limit, routes |
| `crew_agents.py` | CrewAI agents + task recipes (live mode) |
| `demo_data.py` | Orbital maths + instant demo output |
| `LOVABLE_FRONTEND_PROMPT.md` | Paste into **Lovable** to generate a React front end |
| `REPLIT_BACKEND_PROMPT.md` | Paste into **Replit Agent** to generate the CrewAI back end |
| `.replit`, `requirements.txt`, `.env.example` | Replit config |

## Run in Replit (fastest, ~2 minutes)
1. New Repl → Python → upload all files here → press **Run**.
2. Open the preview. Everything works in **Demo mode** (amber pill).
3. For real agents, add Secrets: `OPENAI_API_KEY` and `LLM_MODEL` (or another provider, see `.env.example`). Pill turns green: **Live · CrewAI agents**.

## Lovable front end + Replit back end
1. Deploy the backend on Replit, copy its public URL.
2. In Lovable, paste `LOVABLE_FRONTEND_PROMPT.md`, then set `VITE_API_URL` to that URL.
3. Set `CORS_ORIGINS` on Replit to your Lovable site origin.

## Notes
- Maps and terrain are procedurally generated illustrations, not real NASA imagery or elevation data.
- Figures are planning-level estimates, not mission-certified.
- Keys live only on the server. The browser never asks for credentials.
